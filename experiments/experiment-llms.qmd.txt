**19.** Write Python code that takes the model's raw text output and tries to
parse it as JSON. If parsing fails, print the raw output and the error. Add a
preprocessing step that strips markdown code fences before parsing, since models
often wrap their JSON in them. Test with at least one valid and one invalid input.

```{python}
#| eval: false
# Add your solution here
import json
import re

def parse_model_json(raw_output):
    # Strip markdown code fences if present
    cleaned = re.sub(r"```(?:json)?\s*|\s*```", "", raw_output).strip()
    try:
        return json.loads(cleaned)
    except json.JSONDecodeError as e:
        print(f"Parse failed: {e}")
        print(f"Raw output:\n{raw_output}")
        return None

# Test with valid JSON (with code fences)

# Test with invalid JSON
invalid_output = '{"sentiment": "mixed", "topic": "coding'

print(parse_model_json(valid_output))
print(parse_model_json(invalid_output))
```

## Step 9: MCP — A Common Language for Tools

Model Context Protocol (MCP) is an open standard for connecting AI applications
to tools, data sources, and reusable prompt templates. The key idea is not
technical complexity — it is *standardisation*: define the interface once and
let any client talk to any server.
